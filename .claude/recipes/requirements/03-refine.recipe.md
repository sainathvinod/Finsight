# Recipe — Requirements: 03 Refine (produce Implementation Brief)

**Layer:** recipe (workflow engine). Composes the [requirements skill](../../skills/requirements/SKILL.md). References skills/standards/templates; does not invoke agents.
**Phase:** Generate / Validate.

## Purpose
Produce the Implementation Brief: scoped work, acceptance criteria, and traceability, ready for independent review.

## Required inputs
The scope outline from `02-organize`.

## Standards / templates
[specification-authority](../../standards/specification-authority.md); [requirement-analysis-template](../../templates/requirement-analysis-template.md).

## Ordered steps
1. Fill the Implementation Brief template.
2. For every scoped item, record its approved ID and acceptance criteria.
3. State in-scope and out-of-scope explicitly; list open questions.
4. Self-check: no invented content; every item traces to an approved ID.

## Outputs
A completed Implementation Brief.

## Stop conditions / escalation
A required scope or acceptance item is missing/ambiguous → **Red Card**.

## Prohibited behaviors
Inventing acceptance criteria; issuing a review verdict here (review is separate — see `04-review`).
